Prober MAP Editor v3.0 (6吋純良品版)

系統底層技術規格說明書 暨 產線標準操作手冊

1. 系統環境與架構概述

本系統為專供半導體晶圓測試（CP Test）產線與設備工程師使用之純前端輕量化虛擬地圖編輯工具。本程式（v3.0）核心設計完全基於瀏覽器客戶端運行，不依賴後端伺服器進行編譯或儲存，從源頭杜絕了工廠內部的網通安規風險。

技術底層核心： 系統直接調用 JavaScript 核心的 ArrayBuffer 與 DataView API，在瀏覽器記憶體層級直接進行二進位位元組（Byte-level）的精密封裝與寫入，並透過 JSZip 程式庫即時打包成符合東京電子（TEL）探針台規格的 Product.zip 設定檔。

2. 使用者介面功能導覽

編輯器介面區分為四大主要核心區域，提供直覺且高即時性的互動體驗：

2.1 參數控制台 (Control Panel)

  • 探針台型號 (Model Type)：提供 UF200_LLD 與 UF2000_ULLD 跨世代機型切換，此為底層資料定址（Offset）的重要依據。
  • 平邊角度 (Flat Angle)：支援 0°、90°、180°、270° 四種標準工業晶圓物理平邊（Flat / Notch）取向設定。
  • 系統控制鈕：
    • Reset Map：一鍵清除所有手動標記，回復至向心收斂演算法初始化的預設晶圓狀態。
    • Export Product.zip：啟動二進位串流封裝、Checksum 雙位元組校驗與 ZIP 檔案下載。

2.2 晶圓地圖畫布區 (Wafer Map Canvas)

採用高效 HTML5 Canvas 渲染引擎，將 32 x 32 的晶圓陣列轉化為高動態網格（單一晶粒實體大小為 14px），並支援滑鼠直覺式點擊切換狀態：

  • ■ 綠色區塊 (0x40)：主動測試良品（Active Pass Die）。
  • ■ 紅色區塊 (0x01)：工程師手動標記之無效不良品（Active Fail Die）。
  • ■ 深灰/黑色區塊 (0x00)：落於晶圓外部之跳過不測試區（Skip Area / Background）。

2.3 數據狀態監控箱 (Status Info Box)

即時監控面板，用以動態反饋目前的規格配置（型號、網格大小、角度）與即時晶粒統計（有效測試總顆數、Pass 顆數）。有效測試顆數經演算法控制，初始化時穩定收斂在 500 ~ 700 ea 之間。

3. 核心晶圓空間映射演算法

為了精確模擬真實 6 吋晶圓之物理空間切邊幾何特性，系統在 32 x 32 陣列初始化時導入了「二維歐幾里得距離向心收斂演算法」：

3.1 虛擬中心點與物理邊界

定義矩陣虛擬幾何中心點座標為：Cx = 15.5，Cy = 15.5。設定物理圓形半徑 Radius = 15.2，邊緣不完整晶粒之過濾厚度為 1.2。

3.2 空間區域劃分判定公式

針對網格中的每一個座標 (r, c)，系統透過以下歐氏距離公式計算其與中心點的絕對直線距離：

let dist = Math.sqrt(Math.pow(c - Cx, 2) + Math.pow(r - Cy, 2));

依據 dist 的數值結果，將晶粒硬性劃分為三種狀態：

  1. 內圈測試區域 (Active Area)：當 dist <= (Radius - 1.2)，判定為物理完整晶粒。v3.0 版本全面改採「純良品初始化」，此區域百分之百填入良品代碼 0x40，完全移除隨機不良品。
  2. 邊緣無效區域 (Edge Area)：當距離大於測試區但 dist <= Radius，判定為不完整的切邊晶粒，歸類為 Skip 狀態。
  3. 外部跳過區域 (Skip Area)：當 dist > Radius，歸類為外部背景區。

4. 跨世代機型動態防錯位技術

東京電子一代機（UF200）與二代機（UF2000）在底層二進位架構上存在硬性物理位移。為了防止結構毀損（File Corrupt），編輯器在底層建置了中央共享對象 PARAM_SCHEMA 技術。

4.1 二進位指標位移（Offset）絕對定位對比

由於 UF2000 在底層二進位標頭中預留了更長的管理區塊，導致核心製程參數的暫存器寫入位址整體向後平移了 12 個位元組（bytes）：

參數名稱 資料型態與長度 UF200 絕對位置 UF2000 絕對位置 跨世代實體位移差
DieRowSize (晶粒行距尺寸) uint32 (4 bytes) Offset 12 Offset 24 向後平移 12 bytes
DieColSize (晶粒列距尺寸) uint32 (4 bytes) Offset 16 Offset 28 向後平移 12 bytes
FlatAngle (晶圓平邊角度) uint16 (2 bytes) Offset 30 Offset 42 向後平移 12 bytes
PassBinCode (實機良品代碼) uint8 (1 byte) Offset 32 Offset 44 向後平移 12 bytes
FailBinCode (實機不良品代碼) uint8 (1 byte) Offset 33 Offset 45 向後平移 12 bytes

4.2 自動對齊映射機制

不論是產生負責定義參數結構的 devList.dat，抑或是填入製程數值的 devParm.dat，系統皆會根據使用者當前選定的型號，動態跳轉指標。使用者在網頁 UI 進行變更時，底層的 DataView 就會精準對位，徹底消除產線因型號選錯造成的實機扣機風險。

5. 輸出二進位檔案規格說明

點擊導出時，系統將動態構建 5 個核心快閃記憶體對齊檔案。各檔案規格與物理限制如下：

5.1 dieData.dat (動態晶圓地圖數據檔)

  • 容量限制：UF200 固定為 38,400 bytes；UF2000 固定為 51,968 bytes。
  • 內部架構：前 64 bytes 為保留標頭，隨後以行優先（Row-major）順序填入 32x32 格點狀態碼（良品 0x40、手動不良 0x01、Skip 0x00），結尾最後 2 bytes 為 Checksum。

5.2 devParm.dat (製程參數數值檔)

  • 系統讀取 UI 平邊角度值後，會先進行防呆限幅運算：Math.max(0, Math.min(359, angle))，再依大端序（Big-Endian, false）寫入指定的暫存器。檔案大小與對應機型容量對齊。

5.3 devList.dat (參數結構宣告檔)

  • 自動掃描 Schema，向機台韌體動態通報各參數 ID 與記憶體位置，維持單一源頭宣告（Single Source of Truth），絕不偏離。

5.4 videoData.dat (影像鏡頭硬體定義檔)

此檔案用以定義機台實體光學鏡頭通道，填入錯誤將導致實機光學系統損壞報錯：

  • UF200 模式：長度 38,400 bytes，Offset 11 強制寫入 0x02，宣告實機為雙相機 (2-Camera) 物理架喚架構。
  • UF2000 模式：長度 51,968 bytes，Offset 11 強制寫入 0x04，宣告實機為四相機 (4-Camera) 高速對準系統。

5.5 opParm.dat (操作組態檔)

  • 產生對應容量大小的乾淨預設緩衝區，並全面初始化填入 0x50 旗標以維持實機相容性。

6. 工業級 16-bit 雙位元組補碼校驗機制

為防範地圖數據發生微小 Bit 損壞，TEL 探針台韌體在讀取 dieData.dat 與 devParm.dat 時，會強制執行 Checksum 檢查。本系統對此建置了嚴格的二進位補碼演算：

6.1 校驗碼計算三步驟演算法

  1. 區間累加 (Byte Accumulation)：排除檔案最後 2 個位元組（Checksum 預留位），使用迴圈將前面數萬個位元組的無符號 Uint8 數值進行不中斷累加。
  2. 16位元遮罩截斷 (Masking)：將龐大的加總值與 0xFFFF 進行位元與（AND）運算，強制切除高位元，僅保留低位元的 16-bit 空間。
  3. 二進位求補碼 (Two's Complement)：透過以下標準公式求出二進位補碼：
let checksum = (0x10000 - (sum & 0xFFFF)) & 0xFFFF;
// 以大端序（Big-Endian）寫入檔案最後 2 個位元組：
dv.setUint16(buf.length - 2, checksum, false);

當實機載入此檔案並進行全檔加總（包含此 Checksum）時，總和將剛好發生 16 位元溢出而歸零（Sum = 0），即可順利通過機台的防損毀安全性相容檢查。

7. 產線標準操作步驟 (SOP)

生產前提醒： 請確保使用現代化瀏覽器（建議使用最新版 Google Chrome 或 Microsoft Edge）以獲得最佳的記憶體緩衝區處理效能。
  1. 開啟程式：雙擊開啟 Prober_MAP_Editor_v3.html 網頁。
  2. 選擇目標機型：依據當前派工產線實機型號，在左側下拉選單選擇 UF200_LLD 或 UF2000_ULLD。
  3. 設定物理角度：在 Flat Angle 輸入框中設定晶圓平邊角度（預設為 180）。
  4. 執行晶圓初始化：點擊 Reset Map 按鈕，畫布將自動生成預設純良品（500 ~ 700 顆綠色晶粒）的標準 6 吋向心晶圓地圖。
  5. 手動標記缺陷 (選用步驟)：若產線需進行特定 Bin 變更或手動防呆遮罩，可用滑鼠左鍵直接點擊畫布格點，格點將即時在 🟩 良品 與 🟥 不良品 之間切換。右側數據監控箱將同步即時更新總數。
  6. 導出打包產品包：確認無誤後，點擊 Export Product.zip 按鈕。狀態列顯示“正在打包資料...”後，瀏覽器會自動下載標準的 Product.zip。
  7. 機台部署：將該 Product.zip 解壓縮，並將解開後的 5 個 .dat 檔案，透過工廠網路（FTP）或專體儲存媒介（如 CF 卡）直接載入至 TEL 探針台參數目錄下，即可直接投入線上測試使用。
